AI & INTERACTIVE LEARNING TOOLS | EDUCATIONAL INNOVATION

Designing AI & Interactive Tools for Learning

Challenge: Make emerging technologies more accessible to students while developing practical digital tools that improve instruction, engagement, and classroom experiences.

Role: Application developer, AI innovation strategist, instructional designer, and educational technology specialist.

Built: Three browser-based educational applications:

  • Sight2Motion: A computer-vision learning environment using YOLO object detection that allows students to connect real-world visual input with rule-based robot behavior.
  • Drone Flight Simulator: A virtual CoDrone EDU programming environment that allows students to practice commands and visualize a drone's flight trajectory before programming a physical drone.
  • Student Participation Tracker: A classroom tool that helps educators visualize student participation, discussion turns, interaction patterns, and conversation flow during seminars.

Impact: Created accessible, interactive tools connecting programming, computer vision, simulation, robotics, and classroom practice with authentic learning experiences.

Evidence: Live applications, functional prototypes, classroom implementation, and instructional use cases.
